🛠️ MySQL Environment Setup Reference

1. Download & Install: Download the official MySQL Installer (Community Server and MySQL Workbench) for your operating system. Run the setup wizard using default developer configurations.
2. Download Target Datasets: Go to Alex's official repository: AlexTheAnalyst/MySQL-YouTube-Series. Click the green Code button -> Select Download ZIP. Unzip the folder locally.
3. Database Initialization:
	• Open MySQL Workbench and connect to your local database instance.
	• Go to File -> Open SQL Script -> Select Beginner - Parks_and_Rec_Create_db.sql.
	• Click the Lightning Bolt icon to execute the script. This builds your parks_and_recreation database schema populated with standard testing tables.
4. Data Refresh: For later projects in the course, use the layoffs.csv file from the same directory for data cleaning and exploratory data analysis (EDA) sprints.
